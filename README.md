# 《民國教育委員會》復刻版 (Republic Quiz Arcade)

致敬 1993 年台灣大型電玩街機（Arcade）名作《民國教育委員會》（日版原名：*Quiz Channel Quest*）之現代化 Web 復刻版本。遊戲巧妙結合「大富翁棋盤探索」與「台灣在地文化升學問答」，並具備高自由度的「自訂與更新題庫」系統。

---

## 🎮 遊戲核心特色

1. **學制闖關大富翁（經典主線）**：
   * 玩家從「國民小學」出發，一路晉升至「國民中學」、「高級中學」，直到「最高學府（大學）」光榮畢業！
   * 棋盤格子越往後密度越高、題目難度越刁鑽，隨機穿插校園事件、命運輪盤與保健室。

2. **嚴苛的升學考試（Boss 關卡）**：
   * 每個學制的終點均為「升學檢定考」（大型機台最容易投幣續關之處）。
   * 及格標準隨學程逐級提高；大學畢業考更採取殘酷的「連續答對進度條」，一旦答錯進度倒扣！

3. **隱藏的動態難度設定（Rank 系統）**：
   * 完美還原大型街機後台難度調整邏輯（Rank: 0 ~ 10 級）。
   * 玩家若連續秒答，Rank 會急速飆升，系統將抽出冷門偏門題目反擊！老手玩家可藉由策略性放水或讀秒答題控制難度。

4. **校園福利社與戰略道具**：
   * 答對題目可賺取學分金幣，可在福利社選購：
     * 🔍 **名偵探放大鏡**：50/50 剔除，立即消除兩個錯誤答案。
     * ⏰ **定時懷錶**：當前題目延長 +10 秒作答時間。
     * 🎫 **Pass 免試券**：遇到刁鑽難題可直接換一題。
     * 🧃 **冰鎮養樂多**：立即回復 35 點體力（HP 愛心）。

5. **轉學命運格（跳級／留級）**：
   * 運氣好時，校長宣布天資聰穎，直接「跳級保送」大躍進！
   * 運氣不好被教官抓包違規，面臨罰站倒退與扣血。

6. **9 秒投幣續關（Insert Coin to Continue）**：
   * 體力耗盡時進入緊張的 9 秒倒數接關畫面，投幣即可滿血復活原地續戰！

7. **自訂與動態擴充題庫系統 (CMS)**：
   * 支援直接拖曳上傳 **Excel (.xlsx / .xls)**、**CSV** 與 **JSON** 格式題庫。
   * 內建官方 Excel 範本下載、題庫一鍵匯出、線上視覺化新增與刪除題目。
   * 題庫儲存於瀏覽器 LocalStorage，免架設伺服器即可離線保存與即時生效。

8. **純前端 8-bit 程序化街機音效與 CRT 濾鏡**：
   * 基於 Web Audio API 即時合成街機投幣聲、答對清脆二重奏、答錯蜂鳴器與勝利號角。
   * 內建 CRT 復古顯像管掃描線開關。

## ⌨️ 操作快捷鍵指引

| 按鍵 | 操作功能 |
|---|---|
| **SPACE (空白鍵)** | 擲骰推進 / 關閉答題說明繼續前進 |
| **A / B / C / D** 或 **1 / 2 / 3 / 4** | 選擇對應的第 1~4 個答案選項 |
| **ENTER** | 作答完成後確認前進 |

## 🛠️ 安裝步驟 (Installation)

本專案基於 **Node.js (>= 18)** 開發，請確保本機已安裝 Node.js 與 npm：

```bash
# 1. 複製或進入專案資料夾
cd C:\Users\rossiyeh\SegaProjectHub\quiz

# 2. 安裝相依套件
npm install
```

## 🚀 執行指令 (Usage Commands)

### 啟動本地開發伺服器
```bash
npm run dev
```
啟動後於瀏覽器開啟 `http://localhost:5173` 即可立即投幣遊玩！

### 編譯打包生產環境程式碼
```bash
npm run build
```
建置成品將輸出至 `dist/` 資料夾，為純靜態檔案，可直接部署至 GitHub Pages、Vercel 或任何靜態主機。

### 本地預覽打包成果
```bash
npm run preview
```

## 📑 試算表題庫匯入格式指引

系統支援 Excel (`.xlsx`) 與 CSV 檔案匯入，試算表欄位名稱如下：

| 欄位名稱 (中文相容) | 欄位名稱 (英文) | 必填 | 內容範例 |
|---|---|---|---|
| **學科** | subject | 是 | 國文、數學、自然、社會、流行音樂、體育運動、時事冷知識、藝能 |
| **適用階段** | stage | 是 | 國小、國中、高中、大學、通用 |
| **題目內容** | question | 是 | 「三人行，必有我師焉」出自哪一部儒家經典？ |
| **選項一** | option1 (A) | 是 | 論語 |
| **選項二** | option2 (B) | 是 | 孟子 |
| **選項三** | option3 (C) | 是 | 中庸 |
| **選項四** | option4 (D) | 是 | 大學 |
| **正確答案** | answer | 是 | 1 (或 A) |
| **詳解說明** | explanation | 否 | 出自《論語·述而篇》，說明孔子虛心向學之理。 |
| **難度** | difficulty | 否 | 簡單、普通、困難 |
